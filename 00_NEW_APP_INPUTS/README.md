## Important owner decisions

The files contain recommendations, not silently approved decisions. In particular, the following are unresolved:
- Whether to retain the name **Thikana** after brand/trademark clearance.
- Whether the first public launch should be Dhaka-only or include selected other cities.
- Which property categories are included in the first public release.
- The exact meaning and evidence required for each verification badge.
- Whether to include in-app messaging or only phone/WhatsApp/viewing requests.
- Whether any advance/deposit information can be displayed, given Bangladesh rental law.
- Which hosting region and providers meet Bangladesh data-protection requirements.
- Whether to introduce paid promotion after the marketplace has gained supply and trust.

## Current evidence limitations

- This pack does not contain audited Bangladesh rental-market size or transaction-volume figures. Do not invent TAM or market-share claims.
- Competitor download/review counts are snapshots from public store listings and can change.
- "Verified" competitor claims are not assumed to mean physical property inspection.
- Public competitor policies and user reviews are not proof of operational performance.
- The uploaded intake did not contain the earlier visual screenshots. Copy any chosen reference screenshots into `assets/screenshots/` before UI implementation.

## Safety

Do not place passwords, OAuth secrets, API keys, private keys, signing keys, NID scans, customer data, or production database exports in this folder.
